# Fundamentos de Python

Practicar cómo representar datos, tomar decisiones y dividir un problema en funciones.

## Ejercicios

| Archivo | Qué practica |
| --- | --- |
| [1SeleccionTransporte.py](1SeleccionTransporte.py) | Selección de transporte. Condicionales y valores booleanos para decidir si un viaje es posible. |
| [2DefDescuento.py](2DefDescuento.py) | Cálculo de descuentos. Una función que valida precio y porcentaje antes de calcular el resultado. |
| [3DefRPG.py](3DefRPG.py) | Creación de personajes. Validación de nombres y atributos; construcción de una ficha con cadenas. |
| [4Pin.py](4Pin.py) | Extractor de PIN. Bucles anidados y procesamiento de líneas y palabras para obtener códigos. |
| [5Patron.py](5Patron.py) | Patrón numérico. Generación de una secuencia de texto con un bucle y validación de entrada. |

## Cómo leer este bloque

Este bloque trabaja programación mediante instrucciones y funciones. Los ejercicios con `def` pueden no imprimir nada al ejecutarlos: primero hay que llamar a la función.

## Ejecución

Desde la raíz del repositorio, en PowerShell:

```powershell
py ejercicios/01-fundamentos/1SeleccionTransporte.py
```

Podés sustituir el nombre por otro archivo de la tabla. Si el archivo solo define funciones o clases, ejecutarlo no muestra necesariamente un resultado. Usá `py -i ruta/al/archivo.py` para cargarlo y luego llamar a sus funciones en la consola de Python. Para salir de esa consola, escribí `exit()`.

## Tecnologías

Python 3 y su biblioteca estándar. No hace falta instalar paquetes con pip. En un equipo sin el comando `py`, se puede usar `python` o `python3` según la instalación.
